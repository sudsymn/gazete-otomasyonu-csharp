# gazete-otomasyonu-c#
C# Windows Forms ortamında, File I/O (Dosya İşlemleri) ve nesne tabanlı listeler (List) kullanılarak geliştirilmiş Gazete Yönetim Sistemi. Veriler, ilişkisel veri tabanı (3NF) yapısına uygun biçimde modellenmiş ve yerel metin dosyaları üzerinden 'Data Source' mantığıyla DataGridView nesnesine bağlanmıştır.
